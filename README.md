# 博笛质检报告中心

工程质量验收与报告管理网页，支持钢结构、砖混、内装专项以及非标工程、缺陷巡检和零星工程。

## 主要功能

- 打开网页后直接进入质检工作台，无需登录
- 按工程类型建立验收报告
- 按验收大节点记录检查结论、实测值、整改要求和现场照片
- 单独导出节点验收报告
- 提交竣工审核，审批后形成竣工验收报告并打印为 PDF
- 记录报告创建、编辑、提交和审批操作
- 导出或导入本机业务数据备份
- 桌面端与手机端自适应

## 数据与部署说明

当前 GitHub Pages 版本是本机数据模式，报告和照片保存在当前浏览器。换设备或清理浏览器数据前，请先导出业务数据备份。

正式用于多人、跨设备协作前，还需配置公司后端服务：数据库、图片文件存储、受控分享链接、自动备份与恢复、不可篡改审计日志，以及 HTTPS 域名和运行监控。如以后恢复人员登录，还需增加统一身份认证和服务端权限校验。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

`main` 分支更新后，GitHub Actions 会自动构建并发布 GitHub Pages。
